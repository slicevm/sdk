# @slicevm/cli-darwin-x64

This package contains the prebuilt `slice` binary of the
[Slice](https://github.com/slicevm/sdk) runtime for:

- os: `darwin`
- cpu: `x64`
- Rust target: `x86_64-apple-darwin`

Do not install it directly. Install [`@slicevm/cli`](https://www.npmjs.com/package/@slicevm/cli),
which selects the right platform package automatically through `optionalDependencies`:

```sh
npx @slicevm/cli --version
```

This folder is generated by `scripts/npm/generate-platform-packages.mjs` from
`packages/platforms.json`. Do not edit it by hand.
